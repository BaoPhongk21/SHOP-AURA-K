🔍 TROUBLESHOOTING - CÁC VẤN ĐỀ THƯỜNG GẶP
═══════════════════════════════════════════════════════════════════════

❌ Lỗi: "Cannot connect to database"
───────────────────────────────────────────────────────────────────────
FIX:
  • Kiểm tra DATABASE_URL trên Vercel có đúng không
  • Đảm bảo PostgreSQL server cho phép kết nối từ bên ngoài
  • Nếu dùng Neon/Supabase: Bật "Accept connections from anywhere"


❌ Lỗi: "CORS error" khi gọi API từ frontend
───────────────────────────────────────────────────────────────────────
FIX:
  • Cập nhật FRONTEND_URL trong environment variables
  • Kiểm tra allowedOrigins trong server.js có chứa domain của bạn
  • Restart deployment sau khi thay đổi env vars


❌ Lỗi: "404 Not Found" khi access /api/v1/products
───────────────────────────────────────────────────────────────────────
FIX:
  • Kiểm tra vercel.json routes có đúng không
  • Đảm bảo api/index.js export app correctly
  • Check Vercel build logs có lỗi không


❌ Lỗi: Client không load được (blank page)
───────────────────────────────────────────────────────────────────────
FIX:
  • F12 → Console kiểm tra lỗi
  • Kiểm tra VITE_API_URL trong client env có đúng không
  • Rebuild client: npm run build


❌ Lỗi: "JWT_SECRET is not defined"
───────────────────────────────────────────────────────────────────────
FIX:
  • Thêm JWT_SECRET vào Vercel environment variables
  • Redeploy sau khi thêm
